# 振り返り

観点・物差し・色・ドラフトの形の正典は、この置き場（Base directory）の `detail.md`。
`scripts/` もこの置き場にある。この入口は判定の口を打つところまでで、兆候が無い回は `detail.md` を読まずに済む。

## 1件だけ振り返る（流れから呼ばれたとき）

受け取る値: タスクID と、呼んだ側が渡す受け入れ役の材料 `- 材料: friction=… human=…` の2つの値
（値の意味は呼んだ側の受け入れ役の契約。検証の打ち直し・受け入れでの直し・レビューの指摘は判定の口が台帳から数える）。

1. 判定の口を打つ:

   ```bash
   python3 <Base directory>/scripts/material.py . <タスクID> --gate --friction … --human …
   ```

2. 出力が `QUIET` の1行なら、`detail.md` を読まずに `- 振り返り: 兆候なし` を返して終わる。
3. `SIGNAL` の行が1つでもあれば、`detail.md` の節「1件だけ振り返る」と、そこが指す節「改善の7観点」「色と1行の書式」**だけ**を読んで従う。

返すもの: `## 結果` に入れる `- 振り返り:` の1行（積んだドラフトの ID を添える）。

## 週ごとに振り返る

`tw status` の `retrospect_due` の行が出たとき、`detail.md` の節「週ごとに振り返る」**だけ**を読んで従う。材料は `python3 <Base directory>/scripts/weekly.py .`。

## 観点だけを読むとき（`retro` など）

`detail.md` の節「改善の7観点」「色と1行の書式」を読む。手順は持たず、手で呼んでも何もしない。
