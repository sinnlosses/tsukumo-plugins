# HOLD を決める

入口が `HOLD` のタスクを選び、印を立てずに渡したときの流れ（ユーザーが直接呼んだときだけ選ばれるので、聞ける）。
**委譲せずメインで行う**。サブエージェントはユーザーに聞けないので、委譲すると決める人がすり替わる:
   1. `## 解くべき論点` と `## 注意` を読み、判断の材料を集める。調べもの（コード・文書・記録を
      読むこと）は委譲してよいが、案を選ぶところは渡さない
   2. `AskUserQuestion` で決めてもらう（推す案があれば先頭に置く）。決まらなければ何も書かずに
      「判断待ちのまま」と論点を添えて終了する（`hold` のまま残す）
   3. 決まったら、`tw show T-xxx` の本文の `## 決まっていること（蒸し返さない）` に答えを日付と
      「ユーザー決定」を添えて書き足し（「なし」なら置き換える。front matter は除く）、
      `tw edit T-xxx --status todo --body-file -` で渡す（コミットも `ship` も要らない）
   4. `tw claim T-xxx` で着手の印を立てる。`CLAIMED` なら、その行を受け取った印として `SKILL.md` の手順4aから
      進み、手順4bで並びを呼ぶ（並びが `[]` なら手順5から。決めた答えが本文にあるので、ここからは通常のタスクと同じく委譲してよい）。
      `CLAIMED` 以外なら、行を添えて終了する（`DIRTY`・`UNSHIPPED` などの意味は `task-model` の `tw-reference.md` の表）。
      「やらない」と決まったときも同じく `todo` に戻し、`claim` のあと手順7で `--dropped` にする
