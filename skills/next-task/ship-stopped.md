# 手順8で `SHIPPED` 以外が返ったとき

   | 出力 | すること |
   | --- | --- |
   | `NOTHING` | 送るコミットが無い。Beads 方式で作業の差分が無かったときはこれで閉じている（`SHIPPED` と同じく完了として扱う）。ファイル方式では手順7のコミットを入れ損ねているので、`git status --short` を添えて終了する |
   | `MAIN_DIRTY`・`DIRTY` | 本体（か自分）が汚れている。パスを添えて終了する（`main` は動いていない） |
   | `CONFLICT` | 衝突したファイルを添えて人に預ける（スキルの一覧に `resolving-merge-conflicts` があれば、それで解ける） |
   | `VERIFY_FAILED` | 付け替え後の検証が落ちた（行は `VERIFY_FAILED\t<コマンド>\t<ログのパス>`。落ちた回を残した時刻つきのログ）。ログを読み、落ちた箇所を添えて人に預ける（送っていない） |
   | `RACE` | 3回先を越された。人に預ける |
   | `GIT_READ_ONLY` | `.git` に書けない（送っていない。何も変えていない）。sandbox の外で `tw ship` を打ち直す。打ち直せなければ、行を添えて行の3列目の次の一手を案内し、人に預けて終了する |
   | `STATE_READ_ONLY` | 台帳に書けない（何も変えていない）。行を添えて、行の3列目のとおり `TW_STATE_DIR` か書ける場所を直すよう人に預けて終了する |

## 手順7aの表の残り

   | 出力 | すること |
   | --- | --- |
   | `PRUNED` | `git rm` 済みで stage されている。**タスクのコミットとは別の1コミット**にする。件名は `振り返り済みのタスクファイルを消す（N件）` で、**タスクIDを置かない**（複数タスクをまとめて消す1コミットだから）。いま完了にしたタスクは印があるので消えず、次の回で消える |
   | `DIRTY` | 手順7のコミットに入れ損ねた変更がある。`git status --short` を添えて終了する（捨てない） |
   | `INVALID` | 理由をそのまま報告して終了する（手順7のコミットは送らずに残る） |
   | `GIT_READ_ONLY` | `.git` に書けない（何も消していない）。sandbox の外で `tw prune` を打ち直す。打ち直せなければ、行を添えて人に預けて終了する |
