# 週ごとの振り返り

選ぶ前に `retrospect` を Skill ツールで名前を指して呼び（`retro-step.md` の6aと同じ名前の探し方）、その副ファイル `detail.md` の節「週ごとに振り返る」**だけ**を読んで1回行う。`weekly.py` は retrospect の置き場から打つ（`/loop` から
   回っているときも。出力はドラフトの課題と記録だけなので人がいなくてよい）。記録を1コミットにして
   （ドラフトは Beads に積むのでコミットに入らない）`tw ship` で送ってから、`tw status` を取り直して手順2へ。`tw ship` が `SHIPPED` 以外なら、出力を
   添えて終了する（`${CLAUDE_SKILL_DIR}/finish.md` の手順8の表と同じ扱い）
