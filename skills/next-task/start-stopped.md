# 手順1・手順4で止まるときの扱い

## 手順1の表

   | 終了コード | すること |
   | --- | --- |
   | 6 `MISSING` | タスク運用を始めていない（`.tw/config.toml` か `.beads` が無い）。`/setup-tasks` を案内して終了する |
   | 1・3 | エラー出力か `INVALID` の理由をそのまま報告して終了する（直しに行かない） |

## 手順4の表の残り

   | 出力 | すること |
   | --- | --- |
   | `DIRTY` | 作業ツリーに未コミットの変更がある。`git status --short` を添えて終了する（捨てない） |
   | `UNSHIPPED` | 主ブランチに入っていない自分のコミットがある（前のサイクルが送れていない）。`git log --oneline <主ブランチ>..HEAD`（枝名は `main` 固定ではない。正典「ファイル配置と設定ファイル」）を添えて終了する |
   | `INVALID` | 理由をそのまま報告して終了する |
   | `GIT_READ_ONLY` | 追い付くか枝を切るのに `.git` に書けない（印は立てていない）。sandbox の外で `tw claim` を打ち直す。打ち直せなければ、行を添えて行の3列目の次の一手を案内し、人に預けて終了する |
