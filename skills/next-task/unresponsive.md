# 委譲先の無応答に対応する

5a. **委譲先の無応答に対応する**（手順5で投げたあと、報告が来ないまま長く止まったとき。並列の段の
   担当を起こしたときは、担当それぞれに独立して当てはめる。ほかの担当が返していても、
   残りの担当の無応答は別に扱う）:
   1. **完了の通知が「背景の作業を待っている」で届いたら、待たずにその場で作業ツリーと成果物を見る**
      （通知を受けても放置し、人が指摘するまで気づかなかった実績がある）。
   2. **最後の書き込みから30分ほど動きが無ければ、作業ツリーに手を出さずに止める**（目安であって
      厳密な計測を求めない。進捗を尋ねても返らなかった実績が2件あるので、尋ねる段は必須にしない）。
   3. 止めたら最後の状態と `git diff` を読み、**完了条件を満たしていれば手順6で受け入れる**。
   4. 途中なら、済んだことと残りを明示して**別のサブエージェントに引き継ぐ**。`tw release` で
      捨てるのは差分が使えないときだけ。
